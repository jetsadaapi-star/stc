# STC Label Studio

เว็บแอปสำหรับสร้างฉลากจาก `sticker_revised_outlined.svg` เป็นไฟล์ PDF ขนาด A4 แนวนอน โดยวางฉลากขนาด 7 × 3 ซม. ได้ 24 ดวงต่อหน้า (4 คอลัมน์ × 6 แถว) แบบขอบสติกเกอร์ชิดกันสำหรับตัดต่อเนื่อง

- กำหนดความยาว วันที่ผลิต LOT และจำนวนฉลาก โดยจำนวนเส้นจะใช้ค่าตามสินค้าที่เลือก
- กำหนดจำนวนแยกแต่ละสินค้าโดยใช้ความจุร่วมกันสูงสุด 24 ดวงต่อกระดาษ A4 หนึ่งหน้า
- บันทึกค่าล่าสุดในเบราว์เซอร์และเรียกคืนอัตโนมัติเมื่อเปิดใช้งานครั้งถัดไป
- แสดงหน้าสรุปสินค้า จำนวน ขนาด LOT และวันที่ให้ตรวจสอบก่อนสร้าง PDF
- สร้าง LOT รูปแบบ `PL50-YYMMDD-001` และเพิ่มเลขลำดับให้อัตโนมัติ
- เก็บประวัติงานที่สร้างแล้วสูงสุด 10 รายการสำหรับเรียกค่ากลับมาพิมพ์ซ้ำ
- เริ่มงานใหม่ได้จากแถบหัวเว็บโดยไม่ลบประวัติงาน
- ตรวจสอบว่า QR Code อ่านได้ก่อนยืนยันสร้าง PDF
- แจ้งเตือนเมื่อพบ LOT ซ้ำในประวัติ และต้องติ๊กยืนยันก่อนสร้างไฟล์ซ้ำ
- ชดเชยตำแหน่งงานพิมพ์แนวนอนและแนวตั้งได้ตั้งแต่ -5 ถึง +5 มม. พร้อมบันทึกค่าเครื่องพิมพ์
- ดาวน์โหลดแผ่นทดสอบ A4 แนวนอนที่มีกริดสติกเกอร์ เป้าเล็ง และไม้บรรทัด 100 มม. สำหรับตั้งค่าชดเชยเครื่องพิมพ์
- แปลงความยาวจากเมตรเป็นมิลลิเมตร เช่น 3.00 เมตร เป็น 350x50x3000 mm
- เลือกสินค้าได้หลายรายการและพิมพ์รหัสสินค้าคู่กับ LOT บนฉลาก
- ใช้ฟอนต์ Sarabun ที่ฝังมากับโปรเจกต์
- พรีวิว พิมพ์ และดาวน์โหลด PDF ได้จากเบราว์เซอร์

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

สร้างไฟล์สำหรับใช้งานจริงด้วย `npm run build`
